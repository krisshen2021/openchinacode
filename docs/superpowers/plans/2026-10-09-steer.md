# Steer（插队）功能实现计划

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 用户在 agent 运行中回车排队消息后，可按 Ctrl+S 在最近的安全截断点掐断当前 LLM 流，使排队消息立即进入下一次模型请求。

**Architecture:** 新增 `SessionSteer` 服务（per-instance PubSub 信号）；`SessionProcessor` 增加 `steer()` 与 `Stream.takeUntil` 掐流点（仅在无工具在飞时截断）；`runLoop` 每个 step fork watcher 接线；HTTP 新增 `POST /session/:id/steer`；TUI 新增 `session.steer` 命令（ctrl+s）与 QUEUED/STEER 角标。

**Tech Stack:** Bun, Effect (Stream/PubSub/Fiber), effect HttpApi, SolidJS TUI (opentui)。

**Spec:** `docs/superpowers/specs/2026-10-09-steer-design.md`

**关键已验证事实（实现者不必重查）：**
- `llm.stream`（`packages/opencode/src/session/llm.ts:644-675`）内部用 `Effect.acquireRelease(new AbortController(), ctrl.abort)` 包住整个流；`Stream.takeUntil` 结束消费会关闭 scope 并级联 `ctrl.abort()` 中止 provider HTTP 请求。无需额外 AbortController。
- processor 已有优雅掐流先例：`Stream.takeUntil(() => ctx.needsCompaction)`（`packages/opencode/src/session/processor.ts:661`）。
- 掐断后的收尾由现有 `cleanup()`（`processor.ts:570-612`）完成：文本封口、reasoning 封口、未 settle 工具标 `interrupted`、`time.completed` 落库。
- 工具执行中 `ctx.toolcalls` 非空（entry 在 settle 时才删除，`processor.ts:137-141`），是谓词"无工具在飞"的判据。
- runLoop 下一轮会重读消息（`prompt.ts:1396`），发现排队 user 消息即继续循环——循环主逻辑零改动。

- [ ] **Step 3: 实现服务**

创建 `packages/opencode/src/session/steer.ts`，模式仿照 `packages/opencode/src/session/status.ts`：

```ts
import { LayerNode } from "@opencode-ai/core/effect/layer-node"
import { InstanceState } from "@/effect/instance-state"
import { SessionID } from "./schema"
import { Effect, Layer, Context, PubSub, Queue } from "effect"

export interface Interface {
  readonly signal: (sessionID: SessionID) => Effect.Effect<void>
  readonly watch: (sessionID: SessionID, onSteer: () => void) => Effect.Effect<never>
}

export class Service extends Context.Service<Service, Interface>()("@opencode/SessionSteer") {}

const layer = Layer.effect(
  Service,
  Effect.gen(function* () {
    const state = yield* InstanceState.make(
      Effect.fn("SessionSteer.state")(() => PubSub.unbounded<SessionID>()),
    )

    const signal = Effect.fn("SessionSteer.signal")(function* (sessionID: SessionID) {
      const bus = yield* InstanceState.get(state)
      yield* PubSub.publish(bus, sessionID)
    })

    const watch = (sessionID: SessionID, onSteer: () => void): Effect.Effect<never> =>
      Effect.scoped(
        Effect.gen(function* () {
          const bus = yield* InstanceState.get(state)
          const subscription = yield* PubSub.subscribe(bus)
          return yield* Effect.forever(
            Effect.flatMap(Queue.take(subscription), (id) => (id === sessionID ? Effect.sync(onSteer) : Effect.void)),
          )
        }),
      ) as Effect.Effect<never>

    return Service.of({ signal, watch })
  }),
)

export const node = LayerNode.make({ service: Service, layer: layer, deps: [] })

export * as SessionSteer from "./steer"
```

要点：`Effect.scoped` 包住订阅——watcher fiber 被中断时 scope 关闭、PubSub 订阅自动释放；无订阅者时 `publish` 自然空转，且信号不会滞留给后来的 watcher（PubSub 只投递给活跃订阅）。

```ts
  enabled: status().type !== "idle",
  run: () => {
    if (!props.sessionID) return
    const msgs = sync.data.message[props.sessionID] ?? []
    const completed = msgs.findLast((x) => x.role === "assistant" && x.time.completed)
    const pending = msgs.findLast(
      (x) => x.role === "assistant" && !x.time.completed && (!completed || x.time.created > completed.time.created),
    )
    const queued =
      pending && msgs.some((x) => x.role === "user" && x.time.created > pending.time.created)
    if (!queued) {
      toast.show({ title: "Nothing to steer", message: "No queued message", variant: "info" })
      return
    }
    void sdk.client.session
      .steer({ sessionID: props.sessionID })
      .then(() => toast.show({ title: "Steering", message: "Will interrupt generation at the next safe point", variant: "info" }))
      .catch((error) => toast.show({ title: "Steer failed", message: errorMessage(error), variant: "error" }))
  },
},
```
